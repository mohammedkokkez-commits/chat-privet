# محادثة خاصة (متوافقة مع المتصفحات القديمة جدًا)

محادثة بين شخصين فقط، بدون أي JavaScript في المتصفح — كل شيء (تسجيل الدخول،
إرسال الرسائل) يعمل بنماذج HTML عادية (POST)، وتحديث شاشة المحادثة يتم تلقائيًا
كل بضع ثوانٍ باستخدام `<meta http-equiv="refresh">` بدل الطرق الحديثة.

## متغيرات البيئة المطلوبة

| المتغير | الوصف |
|---|---|
| `USER1_NAME` | اسم المستخدم الأول |
| `USER1_PASSWORD` | كلمة مرور المستخدم الأول |
| `USER2_NAME` | اسم المستخدم الثاني |
| `USER2_PASSWORD` | كلمة مرور المستخدم الثاني |
| `COOKIE_SECRET` | نص عشوائي طويل (32 حرف على الأقل) لتوقيع الكوكيز |

## النشر على Render

1. ارفع المشروع على GitHub.
2. New → Web Service، اختر الـ repo.
3. Build Command: `npm install`
4. Start Command: `npm start`
5. أضف متغيرات البيئة من تبويب Environment.
6. Deploy.
